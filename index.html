Beranda | Changelog

1. Apa itu Media Toolkit?

Media Toolkit adalah aplikasi CLI untuk mengonversi format dan memperbaiki berkas media dengan cepat. Semua proses berjalan secara lokal di perangkat Anda.


2. Sistem operasi yang didukung

Media Toolkit berjalan di Linux, termasuk Android melalui Termux. Dukungan Windows dan macOS masih diupayakan.
