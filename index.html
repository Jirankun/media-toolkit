Media Toolkit

apa itu media toolkit?

Media toolkit adalah : sebuah CLI yang berfungsi untuk melakukan konversi format dan perbaikan file secara cepat dengan CLI (Command Line Interface), tanpa menggunakan internet (semuanya berjalan didalam perangkat anda)


Support untuk sistem operasi apa saja?

Tools ini support untuk Linux, Tetapi akan diusakan support untuk Windows, Termux, dan MacOS
